## ⭐ Review System

The portfolio includes an interactive review section where visitors can:

- Select a 1–5 star rating
- Enter their name
- Write a review
- Submit the review
- View submitted reviews

The project uses **EmailJS** for email notification and browser `localStorage` for storing reviews locally. :contentReference[oaicite:2]{index=2}

> Note: Reviews stored using `localStorage` are specific to the visitor's browser/device and are not currently stored in a centralized database.
